# 1. Introduction

This document represents the beginning of the Atlas AI ERP development journey.

The main objective of this first phase was not only to create a software project, but also to understand how professional projects are organized, documented, and developed using modern development tools.

During this process, I started learning about GitHub repositories, file organization, documentation practices, and the importance of planning before building a complex system.

---

# 2. Project Creation Experience

The first step was creating the Atlas AI ERP repository and understanding how a professional project should be structured.

During this stage, I learned that a repository is more than a place to store code. It is also a place to document ideas, decisions, improvements, and the evolution of the project.

The initial organization was created to separate documentation, future development areas, and project resources.

---

# 3. Repository Organization

The initial project structure was planned as:

```
Atlas-AI-ERP/

├── README.md
├── LICENSE
├── .gitignore

├── docs/
│   ├── devlog.md
│   ├── roadmap.md
│   ├── architecture.md
│   └── learning-report.md

├── backend/
├── frontend/
├── database/
├── assets/
└── tests/
```

However, during the first implementation, the repository was not created exactly as planned.

This was an important learning experience because it showed that organization improves with practice and that mistakes are part of the development process.

# 4. Challenges and Lessons Learned

During this first experience, I faced challenges such as:

* Understanding how GitHub handles folders and files.
* Learning that empty folders cannot exist directly in GitHub.
* Understanding how file paths create folder structures.
* Learning the purpose of documentation files.
* Understanding the importance of project organization.

These challenges helped me understand how developers manage real projects and why good organization is essential.
